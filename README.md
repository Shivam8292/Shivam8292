### 🌟 Featured Projects

#### 🔍 [Reposage — AI-Powered Code Search Engine](https://github.com/Shivam8292/Reposage)
> A semantic code search engine that indexes repositories, chunks code at function level (AST), and performs semantic similarity search with LangChain & ChromaDB.
* **Backend:** FastAPI, Python, Asyncio
* **AI Stack:** LangChain, ChromaDB, Embedding models
* **Frontend:** React, HTML, CSS

#### 📄 [AI Resume Screener with Candidate Ranking](https://github.com/Shivam8292/AI-Resume-Screener)
> A semantic RAG-based candidate ranking system using FastAPI, Llama 3.3 (Groq), and HuggingFace embeddings for high-precision candidate-JD matching.
* **Architecture:** Asynchronous data processing pipeline with Asyncio for low latency.
* **Features:** Explainable scoring output for evidence-based skill matches and qualitative gaps.

#### 🏢 [Corporate Autopsy Machine — Startup Failure Analysis Tool](https://github.com/Shivam8292/Corporate-Autopsy-Machine)
> A RAG-based platform using Gemini 2.0 to automate forensic startup failure analysis and reporting.
* **Core:** Gemini 2.0, RAG pipeline, Python
